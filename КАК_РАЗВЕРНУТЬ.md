# Как развернуть на другой машине

В архиве два способа развёртывания. Выберите один.

## Способ 1 (рекомендуется): офлайн, из готовых образов

Подходит, когда на целевой машине нет интернета или закрыт доступ к Maven Central
и npm registry (именно на этом падает сборка из исходников с ошибкой
`Non-resolvable parent POM ... Read timed out`).

1. Установить и **запустить Docker Desktop** (иконка кита в трее должна быть активна).
2. Перейти в папку `dist_export/` из этого архива.
3. Загрузить образы:
   ```
   docker load -i adminpanel-backend.tar
   docker load -i adminpanel-web.tar
   docker load -i postgres-16-alpine.tar
   ```
4. Запустить (из той же папки `dist_export/`):
   ```
   docker compose up -d
   ```
5. Открыть **http://localhost:18080** (или **https://localhost** — самоподписанный сертификат, подтвердите переход в браузере)

Подробнее — `dist_export/README.md` и `README-DEPLOY-OFFLINE.md`.

## Способ 2: сборка из исходников

Требуется Docker Desktop **и** доступ в интернет (Docker Hub, Maven Central).

1. Запустить Docker Desktop и дождаться полного старта.
2. Запустить `deploy.bat` в корне проекта (выполняет `docker compose up --build -d`).
3. Открыть **http://localhost:18080** (или **https://localhost** — самоподписанный сертификат, подтвердите переход в браузере)

> Важно: frontend внутри Docker намеренно не собирается — раздаётся уже собранная
> статика из `frontend/dist-prebuilt/`. После изменений в `frontend/src/` её нужно
> пересобрать вручную (`npm ci && npm run build` и скопировать `dist/` в
> `dist-prebuilt/`) **до** запуска `deploy.bat`. Причина — см. README.md.

## Остановка

`stop.bat` или `docker compose down`.

## Что где лежит

```
backend/      исходники Java/Spring Boot + адаптированные скрипты поддержки
frontend/     исходники React + dist-prebuilt (готовая статика для nginx)
nginx/        конфигурация реверс-прокси
docs/         документация: HLD, описание backend/frontend/БД, CJM-презентации
dist_export/  готовые Docker-образы для офлайн-развёртывания (способ 1)
deploy.bat / stop.bat / build_and_export.bat   скрипты запуска, остановки, экспорта образов
```

Полное описание системы — `README.md`, процедура редеплоя и типовые проблемы —
`DEPLOY_TASK.md`.
